## Como utilizar os notebooks

Os notebooks podem ser executados no **[Google Colab](https://colab.research.google.com/)**, sem instalação local do Python.

1. Abra o notebook pelo link da monitoria desejada.
2. Selecione **Arquivo → Salvar uma cópia no Drive** para guardar suas alterações.
3. Execute as células em sequência e acompanhe as explicações e os exercícios.
4. Tente resolver as atividades antes de consultar a IA. Use-a para esclarecer conceitos, analisar dados, modificar gráficos e depurar código.
5. Confira os resultados e as explicações geradas pela IA, especialmente quando a análise envolver decisões ou conclusões sobre os dados.

**Atenção:** notebooks que consultam APIs ou outras fontes externas podem exigir conexão com a internet. Os dados e resultados também podem mudar com o tempo.
